# MBB Library Index

A curated subset of the open-source "MBB management consultant" skill (spacemata, MIT licence, see `LICENSE-mbb.txt`). These files sometimes reference other files that were left out because they aren't relevant to competitions (consulting careers, fee negotiation, SOWs, PMI, and so on). Ignore those links.

Read a file only when its topic is needed. Many are 15–60 KB.
